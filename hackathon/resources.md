## Submission requirements (from rules.txt, rule 10)
Every submission must include:

- a clear README
- example structured output
- a demo video showing the working project
- a clear explanation of how Bright Data Scraper Studio is used

Rule 11: AI coding assistants are allowed, but their use must be disclosed.
Rule 7: scraping government websites is not allowed. Scraper Studio blocks them.
